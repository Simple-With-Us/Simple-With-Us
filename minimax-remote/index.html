MiniMax Remote

MiniMax Remote pairs an iPhone app with a companion running on your Mac so you can inspect and interact with sessions.  The iPhone app is currently available by invitation.

Availability

  • iOSBeta awaiting Apple review
Support

What you can do

  • Session view. Check current and recent work from the paired phone.
  • Mac pairing. A companion process on your Mac serves the remote connection.
  • Access. Request current beta details through support.

Scope and data

The MiniMax Remote source repository is private.  Current pairing and network requirements should be confirmed with the beta build.

See the product support page and privacy notice for more detail.
