Credential rotation

Manage supported rotations with an audit trail.

Autorotate coordinates credential updates across configured targets and records their outcomes.  Current source implements verification and hash-linked audit entries.

What you can do

  • Configure targets. Use supported connectors and authorization for each destination.
  • Review outcomes. A rotation may finish committed, failed, or partial.
  • Recover partial work. If a provider revoked an old credential before a later step fails, reconnect the affected target and run another rotation.

Scope and data

Hash-linked entries support integrity checks.  Partial outcomes need operator review and recovery.
