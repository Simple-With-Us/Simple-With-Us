CodeCaps

CodeCaps reads supported quota and reset data from local CLI sessions on macOS 14+; an iPhone companion is in beta.  What is available depends on the provider and credential scope.

Availability

  • macOSmacOS beta download (macOS 14+) ↗
  • iOSCompanion · invite-only beta
Visit website Support

What you can do

  • Quota windows. Check remaining capacity and reset timing where a provider exposes it.
  • Usage and cost. Separate measured API usage and estimated cost from subscription charges.
  • Provider setup. The Mac app reuses local CLI or session credentials.  Optional collector tokens are stored in macOS Keychain; availability depends on the source.

Scope and data

Mac data stays local unless optional endpoint push or pull is enabled.  Unsupported provider readings remain unavailable; review the current build and privacy details before connecting a source.

See the product support page and privacy notice for more detail.
