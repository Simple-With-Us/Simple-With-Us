CodeCaps

Keep AI quota and reset windows in view from the macOS menu bar.  CodeCaps detects runaway usage and usage anomalies, shows local usage history, and keeps selected providers visible in an optional on-top Picture in Picture (PiP) window.

Availability

  • macOSmacOS beta download (macOS 14+) ↗
  • iOSTestFlight beta ↗
Support

What you can do

  • Quota and pacing. Monitor supported plan windows for Claude, Codex, Cursor, Antigravity, Grok CLI, Grok Bot, MiniMax, and Muse.  See remaining quota, reset countdowns, and pacing markers where the provider supplies them.
  • Runaway usage and usage anomaly detection. Compare the current quota burn rate with measured usage history.  Set warning thresholds, see an in-app warning when usage spikes, and review recent alerts alongside the quota history behind them.
  • Picture in Picture. Pin the providers you want in a compact floating PiP window with quota meters and reset countdowns.  Choose a light, dark, or accent background, and optionally open PiP when quota runs low.
  • Reset alerts. Configure reset alarms and notices for detected provider quota restorations.
  • Local readings, optional fleet view. Reuse supported local CLI or session credentials rather than entering provider API keys.  An optional endpoint combines readings from configured Macs.

Screenshots

Demo readings from the Mac app.  Available windows and readings depend on your providers and connected sources.

Scope and data

Mac data stays local unless optional endpoint push or pull is enabled.  Unsupported provider readings remain unavailable; review the current build and privacy details before connecting a source.

See the product support page and privacy notice for more detail.
