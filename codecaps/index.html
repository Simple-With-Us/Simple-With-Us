CodeCaps

CodeCaps monitors available AI plan quotas and reset windows across Claude, Codex, Cursor, Antigravity, Grok CLI, Grok Bot, and MiniMax from the macOS menu bar.  It features dual-cadence monitoring (5-hour and weekly periods), pacing indicators, runaway burn rate alerting with marquee announcements, and an optional on-top PiP widget.

Availability

Support

What you can do

  • Dual-cadence monitoring. Track both 5-hour and weekly quota windows with elapsed-time pacing markers.
  • Runaway alerting. Real-time detection of rapid quota exhaustion with marquee notifications and reset alarms.
  • Forensic vendor resets. Acknowledge manual and automated provider quota restorations mid-cycle with audio and push notices.
  • Local privacy first. Reuses local CLI or session credentials without requiring you to enter provider API keys.

Scope and data

Mac data stays local unless optional endpoint push or pull is enabled.  Unsupported provider readings remain unavailable; review the current build and privacy details before connecting a source.
