Privacy notice

Privacy at Simple With Us

Updated 26 September 2026.  This notice describes the public catalog at simplewithus.com.  Product data flows depend on the app and platform; check each product's own privacy information before using it.

This website

The catalog is a static site hosted through GitHub Pages.  Its current page code does not include an analytics or advertising script.  GitHub Pages and linked resources, including Google Fonts on some pages, may receive ordinary web requests under their own policies.

Opening an external product site, public source repository, download, or TestFlight page sends a request to that destination.  Links are labeled so you can choose when to leave this site.

Product data varies

  • Usage Local Monitor: local tracking data may be combined with direct requests to supported provider services using credentials stored in iOS Keychain.
  • Usage Client Monitor: the iPhone app connects to a Usage Monitor server configured by its user; provider collection and storage happen on that server.
  • CodeCaps: the Mac app can read local CLI session data.  Optional endpoint push or pull is off by default; optional collector tokens use macOS Keychain.
  • ContactLogo: local review, logo network lookups, and optional Google Contacts import or sync have different transfer paths.  Review selected contacts before syncing.

Other product sites describe their own account, broker, contact, or service data practices.  This site-level notice does not replace those product policies.

Contact

If you email feedback@simplewithus.com, your message and address pass through the mail providers used to handle the request.  You can ask about or request deletion of information you sent to this address.  Please do not email passwords, API keys, pairing tokens, or unredacted personal data.
