Shared Tools For A Coding Fleet

AI Fleet Coordinator is a collection of tools, scripts, configuration, protocols, and documentation for a multi-agent coding fleet.

  • Coordinate work with shared issue, chat, and review workflows.
  • Use separate Git worktrees for concurrent tasks.
  • Inspect fleet configuration, tools, and host reports through the shared command-line tooling.
  • Read the public development digest and subscribe to its calendar feeds.

Getting Started

Start with the repository README for the tools, requirements, and setup documentation.  Host-specific capabilities and authorized service access determine which operations are available.

The public fleet digest covers development activity in public repositories.

Related Apps

Muster is the native Mac app for fleet administration.  BotFleet is a separate workspace for running and inspecting bots.
