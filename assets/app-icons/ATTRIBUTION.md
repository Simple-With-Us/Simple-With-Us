# App icon attribution

The slug-named icons in this folder (`<slug>.png`, `socratic-trade.svg`) were copied on 2026-09-25 from the fleet logo set in `jaywedgeworth22/ai-fleet-coordinator` (`agent-logos/app-*.png`, `agent-logos/app-st.svg`) and downscaled to 128 px with `sips -Z 128`.  The CodeCaps icon comes from `jaywedgeworth22/CodeCaps` (`assets/icon-512.png`) instead, because `agent-logos/app-cc.png` currently holds the orange Usage Monitor mark.

Each icon belongs to its own app and repo, all Apache-2.0.  The two-letter files (`ar.png`, `bf.png`, and so on) predate the 200 KB image budget and are slated for removal once every page uses the slug-named icons.

2026-09-27: Socratic Trade uses the current native 3D offset ST icon.  Usage Client and Usage Local use their respective native app icons.  The Clutch site tile uses its plain wordmark without a model-provider symbol.  The shared SWU logo is a full-size re-encoding of the 1920×200 official original, preserving the name and signature.
