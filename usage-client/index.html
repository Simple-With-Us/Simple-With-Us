Usage Client Monitor

Usage Client Monitor connects to a Usage Monitor server you control.  The server polls and stores provider data; the iPhone app presents available history and budgets.

Availability

  • iOSTestFlight beta ↗
  • WebSelf-host from public source ↗
Support

What you can do

  • Server-backed view. See the providers and history configured on your server.
  • Budgets. Review spending limits and available alerts in the client.
  • Setup. Deploy the public server source, then connect the iPhone app to your server URL.

Scope and data

This target requires a reachable Usage Monitor server.  No public hosted signup is offered for this client.
