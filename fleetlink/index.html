FleetLink

Share files, previews, and small static sites through links that expire on a schedule.

Availability

  • iOSApp Clip not installable yet
  • WebWeb app ↗
Contact

What FleetLink Does

FleetLink publishes a file, a folder of files, or a small static site to a share link.  Markdown, images, source files, and HTML previews open in the browser, and a folder that contains an index file is served as a working site.

What You Can Do

  • Preview in the browser.  Markdown, images, HTML widgets, and source code render without a separate download step.
  • Browse a set of files.  A multi-file upload gets a clean directory index with a file-type icon per entry.
  • Control the link.  Expiry is set when you upload, and a share can be password protected or updated in place.

iPhone Availability

The native iOS parent app and embedded App Clip are currently in active TestFlight beta testing.  The web app at fleetlink.online is fully available today.

Scope and Data

Opening a share needs no account.  Uploading needs a token, and a share you protect with a password stays behind that password until it expires.

See the product support page and privacy notice for more detail.

Getting Started

Open the web app to upload a share, or read the project README for self-hosting notes.
