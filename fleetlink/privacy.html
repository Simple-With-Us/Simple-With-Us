FleetLink Privacy Policy

FleetLink is designed around ephemeral, time-bounded storage.  Opening shares requires no account and collects no user identity.

Overview

FleetLink (“we”, “our”, or “us”) provides temporary artifact, file, batch, and directory hosting and custom vanity redirect URLs across the AI fleet and web operators.  This policy applies to fleetlink.online, fleetlink.app, the native iOS app (online.fleetlink.ios), embedded App Clip (online.fleetlink.ios.Clip), MCP server (fleetlink-mcp), and CLI utilities (fleet-share).  You can also view the live standalone policy at fleetlink.online/privacy.

Ephemeral Storage & Automatic Expiration

FleetLink enforces strict Time-to-Live (TTL) expiration schedules on all hosted content:

  • Automatic Pruning: When a share reaches its scheduled expiration timestamp, all underlying file objects stored in Cloudflare R2 and database records in Cloudflare D1 are permanently, irreversibly pruned.
  • Retention Tiers: Unauthenticated guest uploads expire within 6 hours (files) or 24 hours (redirects).  Automated agent token uploads are capped at a maximum of 7 days (defaulting to 3 days).  Vanity redirect links allow retention for up to 180 days (6 months).  Permanent retention is strictly reserved for administrative assets under 500 MB.
  • Passphrase Protection: Uploaders can protect any share with an optional password, gating access behind cryptographic challenge verification before files or directory indexes can be viewed.

What We Collect

  • Uploaded Artifacts: Files, directories, markdown documents, and media that you upload to generate temporary links.
  • Redirect URLs: Target destination URLs provided when creating short redirect links.
  • Account Information: If you sign in (via GitHub, Google, or Apple), we store your verified email address, display name, and provider subject ID to manage active shares in the portal and enforce rate limits.
  • Agent Tokens: Scoped API tokens generated for automated fleet seats, stored in hashed format.

What We Do Not Collect or Sell

  • No Account Required to View: Anyone with a link can preview or download public artifacts without an account or personal data collection.
  • No Data Monetization: We do not sell, rent, monetize, or trade uploaded files or personal information to third parties, data brokers, or advertising networks.
  • No Cross-Site Tracking: We do not use third-party advertising cookies, fingerprinting libraries, or cross-site behavioral tracking.

Infrastructure & Third-Party Services

FleetLink infrastructure is built upon trusted cloud and distribution providers:

  • Cloudflare: Cloudflare Workers (edge compute), Cloudflare R2 (object storage), and Cloudflare D1 (database).  Cloudflare processes network requests and provides privacy-preserving Cloudflare Web Analytics (RUM) measuring performance without tracking cookies.
  • Apple: Distributes the native iOS app and embedded App Clip via App Store Connect and Apple Content Delivery Networks.

User Choices & Immediate Deletion

  • Immediate Deletion: You do not need to wait for expiration to remove data.  You can permanently delete any active share immediately via the web portal at /portal, through the developer CLI (fleet-share --delete <slug>), the MCP tool (fleetlink_delete_share), or by issuing an authenticated DELETE /api/shares/:slug HTTP request.
  • Session Logout: Terminate authenticated sessions at any time by clicking “Sign out”.

Contact

If you have questions about this privacy policy, data practices, or need assistance, email support@fleetlink.online or feedback@simplewithus.com.
