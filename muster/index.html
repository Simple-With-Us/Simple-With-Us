Fleet Administration On Your Mac

Muster is a native SwiftUI app for macOS 14 and later.  It keeps the Mac, the server, and fleet-wide views clearly labeled, so you can see where each reading and action belongs.

  • Inspect configuration compliance and drift, service health, and the tools installed for each coding seat.
  • View server status, resource limits, Operator activity, app processes, and virtual-machine reports.
  • Review plans for supported administration actions before confirming them.

Getting Started

Muster is available as source in the Muster directory and build guide.  Building requires macOS 14 or later, Xcode, XcodeGen, and a valid Developer ID signing identity.  Fleet reports and controls also require the tools and access described in that guide.

Related Tools
