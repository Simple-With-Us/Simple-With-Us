How we describe availability

Release details come from one public file and carry a check date.  Access can change after that check.

  • Shared release facts

    The catalog and product-page availability blocks come from apps/index.json.

  • Specific actions

    A beta button appears only with a product-specific destination.  If no public install link was verified, the page says so.

  • Source and support

    Public source links appear where confirmed.  Every listed product page includes a support route.

  • Privacy by product

    Data flows vary by app and platform.  Review the site notice and the product's own policy.
